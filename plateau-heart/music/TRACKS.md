# Plateau Heart — Music Track Placement Guide

## Christendo 24 — Power Baby Productions

Place your music files (MP3 format) in this directory with the following filenames.
The game engine will automatically load them.

### Required Tracks

| Filename | Usage | Notes |
|----------|-------|-------|
| `boot.mp3` | Console boot sequence | Short jingle, ~5 seconds |
| `title.mp3` | Title screen | Looping, sets the mood |
| `ch1_plateau.mp3` | Chapter 1: Plateau Mont-Royal | Summer vibes, upbeat |
| `ch2_mile_end.mp3` | Chapter 2: Mile End | Evening, artsy/indie |
| `ch3_old_montreal.mp3` | Chapter 3: Old Montreal | Dark, gothic, mysterious |
| `ch4_mont_royal.mp3` | Chapter 4: Mont-Royal Park | Nature, autumn, spiritual |
| `ch5_st_henri.mp3` | Chapter 5: St-Henri | Industrial, gritty |
| `ch6_jean_talon.mp3` | Chapter 6: Jean-Talon Market | Bright, bustling, Italian |
| `ch7_chinatown.mp3` | Chapter 7: Chinatown/Downtown | Neon, rain, cyberpunk |
| `ch8_parc_ex.mp3` | Chapter 8: Parc-Ex/CDN | Winter, multicultural |
| `ch9_hochelaga.mp3` | Chapter 9: Hochelaga | Dusk, rally, intense |
| `ch10_verdun.mp3` | Chapter 10: Verdun (Final) | Epic, winter storm, dramatic |
| `boss.mp3` | Boss battles | Intense, high energy |
| `dialog.mp3` | Visual novel dialog scenes | Atmospheric, subtle |
| `victory.mp3` | Chapter complete jingle | Triumphant, short |
| `game_over.mp3` | Game over screen | Somber but hopeful |
| `shop.mp3` | Shop/between chapters | Chill, shopping vibes |

### From Your Existing Library

Copy your tracks from:
- **8 Bit Music Perfection** folder → Great for retro Christendo 24 feel
- **Plateau Heart music** folder → Purpose-built tracks for this game

If no music files are found, the engine plays procedural 8-bit placeholder tones.
